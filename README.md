# Lantern enquiry desk (Volta Anchor Sprint 5)

A shared enquiry list for Lantern Heat Pumps that fills itself from the website form and info@. Within minutes, it sends the right first reply, gives every enquiry an owner and a next step, merges repeat messages, and takes Rob's calls and notepad photos by email.

- `build/Code.gs`: the Apps Script, which handles sorting, replies, hand-offs and the alarm
- `build/Index.html`: Carla's phone page
- `build/SETUP.md`: how to install it
- `TECHNICAL.md`: the problem, the people, every technical decision and the demo script
- `carla-guide.md`: Carla's one-page guide
- `written-plan.md`: account, cost, alarm, Kevin's note, and what it can't fix

All customer names and emails in tests are made up (example.com). Interview transcripts and Lantern's data aren't in this repo.
